# OceanLauncher Releases

This repository contains public OceanLauncher installers and release metadata.

- `latest.json` contains the newest release and its download URLs.
- GitHub Releases contains the macOS, Windows, and Android installers.

Source code and development builds are maintained privately in
[`OceanLauncher-Development`](https://github.com/OceanEmpirets/OceanLauncher-Development).
